Lab 2: Advanced SQL Queries - Overview

🎯 About This Lab

Lab 2 has been divided into three focused parts to make learning easier and more manageable. Each part covers a specific aspect of advanced SQL queries and can be completed independently.

📚 Lab Parts

Part 1: JOINs and Multi-Table Queries

Topics Covered:

  • Multi-table database schemas
  • INNER, LEFT, and RIGHT JOINs
  • String functions with JOINs
  • Complex multi-table queries
  • Handling NULL values in JOINs

Database: University database (Student, Course, Enrolled)

Start Part 1 →

Part 2: Aggregate Functions and GROUP BY

Topics Covered:

  • Aggregate functions (COUNT, SUM, AVG, MAX, MIN)
  • GROUP BY clause
  • HAVING clause for filtering grouped results
  • COUNT() vs COUNT(DISTINCT)
  • Nested aggregates and complex queries

Database: Company-Product-Purchase database

Start Part 2 →

Part 3: Set Operations and Advanced Queries

Topics Covered:

  • UNION and UNION ALL operations
  • Multiset operations
  • UPDATE and DELETE with multiple rows
  • SQL Division pattern
  • Complex nested queries and subqueries

Databases: Multiple examples including Product/Company and Student/Enrolled

Start Part 3 →

💡 Learning Path

We recommend completing the parts in order (Part 1 → Part 2 → Part 3) as each builds on concepts from the previous parts. However, Part 2 and Part 3 include their own database setup sections, so they can be completed independently if needed.

📋 Prerequisites

  • Completion of Lab 1 or equivalent knowledge
  • Understanding of basic SQL operations
  • Familiarity with primary and foreign keys
